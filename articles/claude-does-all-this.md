**多数人只用到 Claude 的 10%，而自己并不知道。**

打开一个聊天，问点什么，复制回答，关掉。几乎所有人都是这么用的。

但 Claude 有一堆大多数人从没碰过的功能：记忆、能在聊天里直接运行的应用、你睡觉时自己执行的任务、浏览器控制……

这份指南里有全部内容：

→ 每个功能在哪里 → 怎么开启 → 一段可以直接复制、今天就能试的 prompt

每一项的配置都在几分钟以内。从那之后，它每天帮你省时间。

## 第一部分：聊天里就有、你却没用过的东西

![第一部分目录卡：聊天里自带却没人配置的四项，01 Projections 每个聊天带固定指令与文档、02 Artifacts 在对话里就能运行的应用、03 扩展推理回答前逐步思考、04 记忆不用重复介绍自己](/sdlc-playbook/articles/claude-does-all-this/parte-1.jpg)

**1. Projects：别再每个聊天里重新自我介绍**

每个新聊天都从零开始。它不知道你是谁、做什么、喜欢什么样的回答方式。大多数人认了，于是一遍又一遍重复同样的背景。

Projects 解决这个问题。创建一个项目，上传你的文档，写几条固定指令，Claude 在这个项目的所有聊天里都记得。下周回来，它还知道上下文。

如果你从没用过 Projects，从这儿开始。

可以直接贴进项目指令的例子：

```text
你是我的内容研究助理。我有一份面向懂行读者的 AI 与科技 newsletter。

不要解释基础概念（什么是 LLM、什么是 API）。

当我给你一个主题或一篇文章时：
1. 给我找出 3 个最反直觉或最出人意料的角度
2. 把它和我可能漏掉的近期新闻联系起来
3. 建议怎么把它讲成一个故事，而不是一份摘要

语气：直接，不用公司腔，不注水。
格式：短段落，除非我要求否则不用列表。
永远不要用「好问题！」之类的开头。
```

**2. Artifacts：在聊天里就能运行的应用**

很多人以为 Claude 只会写文字。错了。

用 artifacts，Claude 能做出真正能用的东西：计算器、习惯追踪器、小游戏，加带图表的 dashboard。不是那种要复制到别处去的代码，它当场打开、当场点击、当场使用，还能用一个链接分享出去。

它还能画 SVG 图表、示意图和交互式可视化。

试试看：

```text
给我做一个网页版习惯追踪应用。

我想跟踪 5 个每日习惯，每天打卡。
每个习惯显示一条 7 天的连续记录。
如果断了一天，连续记录归零。

设计：深色背景，极简风格。
打卡时要有一点让人愉悦的小动画。
数据要能在刷新页面后保留。
```

**3. 扩展推理：让它先想再答**

开启扩展推理后，Claude 会在给出答案前一步步分析问题，而且你能看到这个过程。

快问快答用不着。但在复杂决策、战略分析，或任何你希望它真正动脑子的场合，差别非常大。

做个实验：同一个问题，开与不开各问一次，对比一下。

重要决策时可以用的 prompt：

```text
我要在两个选项里做选择，希望你先冷静想清楚再回答。

选项 A：[描述选项 A]
选项 B：[描述选项 B]

我的处境：[背景、约束条件、我最在乎什么]

回答之前，分析：
- 每个选项的二阶、三阶后果
- 我因为情绪在高估或低估什么
- 我还缺哪些一旦补上就可能改变决定的信息
- 如果事情办砸，哪个选项能更好地保护我

然后给我你真实的建议，以及理由。
```

**4. 记忆：不用每次重复介绍自己**

开启记忆后，Claude 会把你的重要信息存下来：你的职业、在做的项目、喜欢它用什么方式跟你说话。

打开一个全新的聊天，它已经有上下文了。再也不用每次自我介绍。

在设置里开启。想加速这个过程，可以直接告诉它：

```text
我要你记住这些关于我的信息，免得我反复重复：

我叫 [名字]。在 [公司或项目] 做 [职位]。
当前重心是 [在做什么]。
我的读者/客户是 [人群]。

之后我找你帮忙时，默认带上这些背景，除非我另有说明。
你跟我说话的方式：[直接 / 详细 / 随意 / 正式]。
回答里让我反感的东西：[如列表、冗长开场、过多免责声明]。

把这些存进你的记忆。
```

## 第二部分：给它一个角色，整个体验都会变

![第二部分目录卡：给它一个角色，05 心理咨询师用提问代替建议、06 无滤镜导师找出计划断裂处、07 私人教练按你的情况排真实计划、08 对话排练先练再上场、09 魔鬼代言人构造最强反方](/sdlc-playbook/articles/claude-does-all-this/parte-2.jpg)

Claude 不必是一个泛泛的「AI 助手」。给它一个具体角色，它会认真对待：问你的问题会变，跟你争的点会变，放过你的地方也会变。

以下任何一段，复制到新聊天的开头即可。

**5. 让你想通问题的「心理咨询师」**

通常你讲一个困扰，得到的回答是「我理解这很难」加五条通用建议。

这段 prompt 把它变成更接近认知行为治疗师的角色：用提问代替建议，质疑你的思维方式而不是顺着你。

适合反复纠结的决定，或者需要跳出来看局面的情形。注意：它是帮你理清思路的工具，如果你真的很难受，不能替代专业人士。

```text
扮演一位有 20 年经验的认知行为治疗师。我要跟你说一件让我困扰的事。

你的工作方式：
- 不要一上来就给建议。通过提问让我看清自己的思维模式。
- 识别认知扭曲（灾难化、非黑即白、读心、预言未来）并指出来。
- 一次只问一个问题。不要让我应接不暇。
- 目标是让我自己得出结论，不要直接喂给我。
- 亲近但诚实。如果我的推理是扭曲的，不要顺着我。
- 如果你察觉我在回避什么重要的东西，直说。

不要临床式的开场白。直接问我怎么了。
```

**6. 无滤镜导师**

默认情况下，Claude 倾向于附和你的想法、帮你找亮点。要验证一个计划，这恰恰是你不需要的。

这段 prompt 关掉客气模式。它专找站不住脚的假设、你没考虑到的盲区，以及你的计划会断掉的确切位置。

听着扎心。所以有效。

```text
你是一位极度诚实的导师。你创过业也搞砸过，见过几百个人在深信自己正确时犯下同样的错误。

你的工作不是给我打气，而是在我犯下昂贵错误之前，挡住我的盲点。

规则：
- 如果你认为我错了，直说，并具体解释为什么。
- 指出我没看到的东西，尤其是那些因为盼着计划成功而刻意回避的。
- 问出那些我不敢问自己的尖锐问题。
- 如果这是个坏主意，就说是。不要用「另一方面……」来找补。
- 永远以「继续之前我最该想清楚的一件事」收尾。

我要讲一个想法。不要客气。
```

**7. 私人教练**

网上有无数通用训练计划，没有一个考虑你的时间表、伤病史、器械条件和真实目标。

把你的数据给它，Claude 给你排一个真计划。你每周反馈，它跟着调整。

```text
扮演资深私人教练兼运动营养师。我要你为我设计一套完整方案。

我的情况：
年龄：[年龄]
体重 / 体成分：[数据]
目标：[减脂 / 增肌 / 耐力 / 全面体能]
器械：[健身房 / 家里 / 只有小哑铃 / 等]
每周天数：[次数]
每次时长：[分钟]
伤病或限制：[详情，或「无」]
当前水平：[新手 / 中级 / 高级]

设计一个 12 周方案，每周的动作、组数、次数和组间歇都写清楚。给我讲清楚结构背后的逻辑，我要理解它，不只是执行它。我每周会告诉你进展，你据此调整。
```

**8. 排练一场艰难对话**

几乎所有人都在毫无准备的情况下走进艰难对话。知道自己想说什么，但不知道对方会怎么回。

让 Claude 扮演对方。而且要演得真实：按那个人的方式回应，在你的论点站不住时反驳你，逼你把结果赢下来。排练两轮之后，真实对话会容易得多。

```text
我要准备一场艰难的对话，希望你扮演对方来陪我练习。

对方：[是谁：上司、客户、合伙人等]
我要说的：[需要请求或告知什么]
我为什么发怵：[担心发生什么]
对方的性格：[个性、通常的反应、在乎什么]

保持在角色里。按那个真实的人会有的方式回应，而不是按我希望的方式。如果我说得含糊或没有说服力，反驳我。

每一轮交锋后，暂时跳出角色，告诉我哪些有效哪些没有，然后再回到角色里。最后给我一份完整分析：我哪里做得好、要改什么、真实对话中要注意什么。

现在直接进入角色，等我先开口。
```

**9. 魔鬼代言人**

你已经决定了。弊端也想过了。你确信自己是对的。

恰恰在这个时刻，让 Claude 攻击这个决定。不要客气的「一些顾虑」：要完整的反方论证，加上最现实的三种翻车方式。

在你下场前花五分钟做这件事，而不是之后。

```text
我已经做了一个决定，在押上去之前，我要你构造出尽可能强的反对论证。

决定：[具体要做什么]
我的推理：[为什么认为这是好主意]
我已经考虑过的：[想过的反对意见]

你的任务：
- 构造最强的「反方」论证。
- 不要用积极面来平衡。那些我自己已经信了。
- 找出我默认为真、但其实可能为假的假设。
- 描述这件事最现实的三种失败方式。
- 告诉我在低估什么。
- 告诉我：要让这件事成为真正的坏主意，我需要相信什么。

不留情面。如果这是个错误，我现在就需要知道。
```

## 第三部分：聊天之外的 Claude

![第三部分目录卡：聊天之外，10 Claude in Chrome 替你读页点击填表、11 你的文件直接操作电脑文件夹、12 定时任务按你说的时间自己执行、13 Skills 装一次的新能力、14 CLAUDE.md 每次会话自动读的规则、15-16 Claude Code 与设计替你编程测试和设计](/sdlc-playbook/articles/claude-does-all-this/parte-3.jpg)

**10. Claude in Chrome：和你看到同一屏**

常见做法是 Claude 开在一个标签页里，所有内容手动复制粘贴。这是慢的方式。

Claude in Chrome 是一个扩展，让 Claude 能访问你打开的那个标签页并在里面操作：读页面、点击、填表单、跳转 URL。你用自己的话描述任务，然后就可以不管了。

如何开启 → 在 Chrome 应用商店搜「Claude」，安装，登录账号，从图标打开侧边栏。

示例任务：

```text
我在这个招聘信息页面上。

检查所有可见的职位，提取：岗位、公司、薪资范围（如有）和前 3 条主要要求。

给我一张按薪资从高到低排序的对比表。

如果有下一页，翻过去继续，直到覆盖全部。
```

**11. 处理你的文件：Claude 在你电脑上**

在网页版里，Claude 看不到你的电脑，什么都要手动贴进去。

用桌面应用，你可以把电脑上的文件夹连接给它。它读你的真实文件、编辑文档、创建新文件、整理文件夹，不用往聊天里复制任何东西。它还能在你干别的时处理长任务：你只要最终结果，它交付成品。

以前独立的那个应用（Cowork）现在直接整合进 Claude 了。

**12. 定时任务：你睡觉时它干活**

多数人只在打开 Claude 时用它。问一句，等回答，关掉。

定时任务让你配置一次，Claude 就按你说的时点自己执行：每天早上、每周一、每小时。不需要你做任何事。

直接在聊天里跟它说就行。例子：

```text
创建一个定时任务，每个工作日 7:30 执行：

1. 检索过去 24 小时最重要的 AI 新闻
2. 选出最要紧的 5 条：令人意外、反直觉，或对 AI 从业者有真实影响
3. 每条写：标题、两句话摘要、为什么重要
4. 存为 "brief-[日期]"

语气直接、有分析性。不注水。3 分钟内能读完。
```

**13. Skills：像装应用一样装新能力**

Skills 是一组指令包，教会 Claude 做某一类具体任务。不用每次解释你要的方式，装一次它就会了：做 PowerPoint、处理 PDF、遵循你们公司的工作流……

类比手机：没有应用也能用，但装对了应用能做的事多得多。

可以用自带的，加组织内的，也可以让 Claude 把你经常重复的某个流程做成一个 skill。

**14. CLAUDE.md：每次都会读的规则**

在 Claude Code 里，你可以在项目文件夹建一个 CLAUDE.md 文件。每次会话开始时 Claude 自动读它，不需要你提醒。

你的代码约定、风格规则、公司术语、品牌语气。写一次，这个项目的所有会话都遵守。

```text
# 项目：AI Newsletter

## 项目概况
面向 builder 和投资人的周更 AI newsletter。35,000 订阅者。语气直接、有分析性、带一点讽刺。

## 写作规则
- 短段落，每段最多 3 句。
- 正文不用列表，只用散文。
- 不用长破折号，用逗号或改写句子。
- 数字胜过形容词：「省 3 小时」而不是「省很多时间」。
- 禁用词：「革命性」「颠覆」「协同」「赋能」。

## 内容规则
- 读者知道什么是 LLM，不要解释基础概念。
- 从最出人意料的地方开头。
- 每篇文章都要有明确的「所以呢」：读者该做什么、该改变什么想法。

## 文件结构
- 草稿在 /borradores
- 已发布在 /publicados，文件名带日期：YYYY-MM-DD-标题.md
- 研究笔记在 /investigacion
```

**15. Claude Code：替你写代码、跑测试、修 bug**

还有人不知道 Claude 会编程。完整功能、复杂重构、可上生产的代码，说的已经不是零散片段。

Claude Code 更进一步。它在你的开发环境里工作：读你的代码、写新代码、跑测试、读报错、循环修复直到完成。

终端、网页、桌面应用、手机上都有。集成 VS Code 和 JetBrains，还能放进 GitHub Actions，让它审查或编写 pull request，你一个手指都不用动。

**16. 设计：不打开 Figma 做落地页和演示文稿**

很多人不知道 Claude 也会设计。One-pager、演示文稿、原型、App 界面、落地页。

你描述需求，它在一个你可以自己编辑的画布上构建。之后按需要的格式导出。对不会设计的人，3 小时的 Figma 变成 10 分钟的对话。

```text
为 [产品] 设计一个落地页。
受众：[给谁看的]。
一个带标题和 CTA 的 hero 区，三个带图标的卖点，用户评价，一个联系表单。
深色、现代风格，大字号排版。
```

## 第四部分：给开发者

![第四部分卡：Prompt caching，重复 token 的成本对比条从无缓存的 100% 降到一成，配 cache_control ephemeral 的代码块；缓存持续 5 分钟，每次使用续期](/sdlc-playbook/articles/claude-does-all-this/parte-4.jpg)

**17. Prompt caching：重复 token 最高便宜 90%**

如果你在用 Claude 的 API，而你的调用里反复带着一大块上下文（长 system prompt、参考文档、代码库），你每次都在为处理同样的 token 付费。

Prompt caching 把这些内容存在服务端，后续调用直接复用。结果：

→ 缓存命中的 token 最多便宜 90% → 响应明显更快

如果你在做有一定规模的产品而没用它，就是在烧钱。

怎么做 → 给要缓存的块加上 "cache_control": {"type": "ephemeral"}。

默认缓存持续 5 分钟，每次使用都会续期。适用于 system prompt、长文档和工具定义。

```json
{
  "model": "claude-opus-5-5",
  "system": [
    {
      "type": "text",
      "text": "[你的长 system prompt 或参考文档]",
      "cache_control": {"type": "ephemeral"}
    }
  ],
  "messages": [
    {
      "role": "user",
      "content": "[用户消息，每次调用会变]"
    }
  ]
}
```

第一次调用把 system prompt 存进缓存。接下来的调用，只要在 5 分钟以内，直接复用：更便宜也更快。

## 第五部分：最冷门的

![第五部分卡：暗色视频剪辑终端示意（CLIP_FINAL.MP4，0:12→1:45 转 9:16，ffmpeg 命令行），下列 18 视频剪辑、19 连接器（Gmail、日历、Drive、Notion）、20 照片转表格](/sdlc-playbook/articles/claude-does-all-this/parte-5.jpg)

**18. 不开剪辑软件剪视频**

这件事几乎没人知道：Claude 能剪视频。不是拖时间线那种；它写出并执行完成剪辑的代码（通常用 ffmpeg，很多剪辑软件底层就是它）。

在 Claude Code 和桌面应用的文件模式下可用。把视频给它，告诉它你要什么，它交付结果。

它能做的：

→ 剪切段落、拼接片段、去除静音 → 横屏转 9:16 竖屏，发 Reels、TikTok、Shorts → 提取音频、压缩、转格式 → 加速、减速、把片段转 GIF → 用同一套参数一次处理 50 个视频

创意剪辑替代不了 Premiere。但重复劳动能省下几小时。

```text
给你这个视频。我要：
```

**19. 连接器：Claude 进到你的 Gmail、日历、Notion 里**

默认情况下，Claude 看不到你的邮件和日程。装上连接器就可以。

在设置里连接 Gmail、Google 日历、Drive、Notion 等一大批应用，Claude 就能在它们之间检索、读取、交叉信息。什么复制粘贴都不用。

```text
查一下我本周的邮件和明天的日程。
告诉我明天有哪些会、哪些邮件需要在会前回复，并给最紧急的两封起草回复。
```

**20. 从照片到表格**

Claude 能看懂图片。这远不只是「描述照片」。

→ 拍一张小票或发票 → 出一张含品项、金额、税额的表 → 截一个报错 → 告诉你哪里坏了、怎么修 → 拍一块写满字的白板 → 整理成带待办的摘要 → 截一张你喜欢的网页 → 还原成 HTML 原型

```text
给你 8 张差旅票据的照片。
每张提取：日期、商户、总金额、税额。
做一张表格，一行一张票据，末尾加合计。
```
