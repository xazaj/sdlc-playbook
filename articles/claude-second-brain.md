「第二大脑」这个词听着有点玄，说白了就是几个文件夹里放着一批文本文件，由根目录的一份索引文件告诉 AI 该去哪里找。不装 Obsidian，不建数据库，也不上笨重的应用，就是躺在硬盘上的普通 Markdown。

![原文封面图](/sdlc-playbook/articles/claude-second-brain/01-cover.jpg)

这篇文章从零搭一遍这套结构：目录怎么组织、路线图（CLAUDE.md）怎么写、命名遵守什么约定、agent 又是怎么解析这一切的。跟着做完，你会得到一套可以直接复制、马上往里填内容的系统。

## 简短回答

「第二大脑」就是一批平面 .md 文件，按内容分放在几个简单文件夹里，根目录再放一份 CLAUDE.md 当索引。它告诉 agent 信息在哪里、文件怎么组织、读取要遵守什么协议。最重要的一条规则：一个文件只写一个主题。CLAUDE.md 是 agent 在你的知识里导航用的地图，你不需要为此装任何专门的笔记应用。

需要的东西只有三样。一个能读项目目录的 AI agent，Claude Code 或同类都行；随便什么文本编辑器，这些是标准 .md 文件，什么都打得开；再加五分钟，搭好文件夹就够了，内容不必一次填齐，边用边补。

没有安装脚本，也没有复杂配置。这是文件结构和一份索引，不是一个软件产品。

## 原则：平面文件优于应用

想下载 Obsidian、或者去 Notion 里搭一个漂亮数据库的冲动，通常是个陷阱。应用会带来自己的专有格式、存储逻辑和界面，这些常常给 AI 制造摩擦。agent 最好的工作方式是直接读你硬盘上的纯文本文件，中间不隔任何一层。

所以这套东西的地基是平面 Markdown。「平面」指带标准格式（标题、列表）的纯文本，没有嵌套数据库，没有专有链接。它在任何地方都能打开，人和 AI 都读得懂。简单本身在这里就是优势：格式越干净，横在你的知识和 agent 之间的墙越少。

## 骨架：三个语义文件夹

布局按内容语义分组，基本结构是这样：

![目录结构示意](/sdlc-playbook/articles/claude-second-brain/02-folders.jpg)

三个核心文件夹几乎覆盖所有场景：

- notes/：事实与主题条目。学到什么，蒸馏成文件放这里。一个主题一个文件。
- people/：联系人或公司的卡片：是谁、谈过什么、关键细节。一个人一个文件。
- projects/：项目状态：正在做什么、停在哪里、下一步是什么。

根目录再放三份工作流的元数据文件：MEMORY.md 存长期的核心信息，LEARNINGS.md 存经验教训，decisions.md 存决策的审计记录。

## CLAUDE.md 是地图

文件夹只是仓库；要让它们能被用起来，还需要一张地图。根目录的 CLAUDE.md 告诉 agent 怎么解读你的结构。

为什么是 CLAUDE.md？用 Claude Code 的话，它会在启动时自动把这份文件装进系统提示。你不用吩咐 agent「先读地图」，在你提第一个问题之前，它已经知道规矩了。

地图文件长这样：

![CLAUDE.md 地图文件示例](/sdlc-playbook/articles/claude-second-brain/03-map.jpg)

进阶一招是 @ 引用：CLAUDE.md 里可以用 @ 路径直接引用核心文件，比如写上 @MEMORY.md 或 @decisions.md，agent 就会把这几份高层上下文一直留在工作记忆里。省着点用，只给真正需要持续在焦点里的东西。

## 命名纪律

「一个文件一个主题」这条规则，决定大多数系统的成败。

- 一个文件一个主题：别把几件不相干的事倒进同一份 notes.md。写的是税收政策，就建 tax-policy.md。
- 主题即文件名：文件叫它装的东西，用 ivan-petrov.md，不用 note-12.md。
- 风格统一：一律小写加连字符，不留歧义。

## agent 怎么读这套结构

会话开始时，agent 先读 CLAUDE.md。你提问，它按地图定位到正确的文件，解析，然后带着引用合成答案。信息不在库里时，它会报告找不到，而不是编一个。你唯一要负责的是维持结构干净，检索的事归 agent。

![常见坑清单](/sdlc-playbook/articles/claude-second-brain/04-pitfalls.jpg)

## 常见问题

- 地图必须叫 CLAUDE.md 吗？用 Claude Code 就必须，它是自动加载的；其他 agent 用 README.md 或等价的根目录索引。
- 一开始建几个文件夹？从简：三个主文件夹加根目录文件，等某个主题大到装不下了再给它开目录。
- 旧笔记要全部搬过来吗？不用。骨架先搭起来，内容边用边迁、边用边建。

## 底线

你的第二大脑，就是平面 .md 文件、严格的「一个主题一个文件」纪律，加上一份给 agent 导航的 CLAUDE.md 地图。别惦记复杂软件了，把文本文件在硬盘上放整齐就行。时间要花在地图上：一份清晰的 CLAUDE.md，就是一团乱麻和一个能干活的 AI 助手之间的全部差别。
