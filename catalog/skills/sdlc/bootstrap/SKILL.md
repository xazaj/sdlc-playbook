# 开局与约定选型

读取决策矩阵，针对用户当前的项目给出一个建议。

决策矩阵：`~/.sdlc/stages/10-bootstrap/DECIDE.md`（`~` 为当前用户家目录）

## 用法

0. 执行 `~/.sdlc/bin/check-update.sh`。脚本已节流，最新时静默；若有输出，转告用户后继续。
1. 以下三项若未知，先向用户确认，每次只问一项：agent 的产出给谁读（自己、团队、还是项目外的人）？会有长任务放手执行吗？产出被认出是 AI 写的会造成实际损害吗？
2. 读取 DECIDE.md，依据「判断依据」与「推荐路径」两节定位该立的约定（文风约束、去 AI 味、自主执行，可叠加，出现信号再装）。
3. 给出一个明确建议并说明理由，指向对应的登记卡。不罗列全部选项让用户自行挑选。
4. 若问的是「需求写到多细」「界面用哪套设计系统」「这次改动要不要先写测试」，分别改走 `~/.sdlc/stages/15-define/`、`20-design/`、`30-coding/` 的 DECIDE.md；本矩阵只管开局时立什么常驻约定。

不复述 DECIDE.md 全文。
