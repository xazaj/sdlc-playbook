# 开发流程选型

读取决策矩阵，针对用户手上这次具体改动给出**一个**建议。

**决策矩阵：** `~/.sdlc/stages/30-coding/DECIDE.md`（`~` 为当前用户家目录）

## 用法

0. 先跑 `~/.sdlc/bin/check-update.sh`。它平时静默，只在知识库落后于远端时输出一行 —— 有输出就转告用户，然后继续。已节流，不会每次都发网络请求。
1. 若以下三点未知，先问清楚（一次一个，别连珠炮）：这次改动写错了多久会被发现？范围多大？需求确定吗？
2. 读上面的 DECIDE.md，按"判断依据"和"推荐路径"两节定位。
3. 给出一个明确建议并说明理由，**不要罗列全部选项让用户自己挑**。
4. 若这次改动要交给 agent 自主执行，必须读"交给 agent 执行时的差异"一节 —— 结论与人类独自编码时不同。

不要把 DECIDE.md 整篇复述出来。
