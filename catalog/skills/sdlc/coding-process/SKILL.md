# 开发流程选型

读取决策矩阵，针对用户当前的具体改动给出一个建议。

决策矩阵：`~/.sdlc/stages/30-coding/DECIDE.md`（`~` 为当前用户家目录）

## 用法

0. 执行 `~/.sdlc/bin/check-update.sh`。脚本已节流，最新时静默；若有输出，转告用户后继续。
1. 以下三项若未知，先向用户确认，每次只问一项：错误多久会被发现？改动范围多大？需求是否确定？
2. 读取 DECIDE.md，依据"判断依据"与"推荐路径"两节定位。
3. 给出一个明确建议并说明理由。不罗列全部选项让用户自行挑选。
4. 若改动将交给 agent 自主执行，必须读"交给 agent 执行时的差异"一节，其结论与人工编码不同。

不复述 DECIDE.md 全文。
