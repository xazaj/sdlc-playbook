# 设计方案选型

读取决策矩阵，针对用户当前的具体界面给出一个建议。

决策矩阵：`~/.sdlc/stages/20-design/DECIDE.md`（`~` 为当前用户家目录）

## 用法

0. 执行 `~/.sdlc/bin/check-update.sh`。脚本已节流，最新时静默；若有输出，转告用户后继续。
1. 以下三项若未知，先向用户确认，每次只问一项：界面预期存续多久？大约几屏？是否需要品牌辨识度？
2. 读取 DECIDE.md，依据"判断依据"与"推荐路径"两节定位。
3. 给出一个明确建议并说明理由。不罗列全部方案让用户自行挑选。
4. 若界面将交给 agent 生成，必须读"交给 agent 执行时的差异"一节，其内容是如何避免模板感。

本技能只负责选方案。方案选定后的视觉实现，交给 frontend-design 一类实现技能。

不复述 DECIDE.md 全文。
