## 已知待验证的问题

以下是挂载时就已看到的疑点，实际用过才能确认严重程度：

1. **路径硬编码** —— SKILL.md 里写死了本机绝对路径。换机器或别人安装就废。是否值得为此写构建器，取决于是否真的要跨机器用。
2. **DECIDE.md 篇幅** —— 71 行。agent 每次会全文读取，是否需要拆分到 references，用过才知道。
3. **第四节"落地资产"目前是空的** —— 没有 catalog 条目可指。这一节在早期是否该存在，存疑。
4. **单个路由技能无法验证触发区分度** —— 只有一个技能时，它要么总被选中要么总不被。需要第二个 DECIDE.md 才能测出 description 是否写得够准。
5. **MANIFEST.yaml 未创建** —— spec 要求每个阶段目录含它，但 M0 无校验器消费它，现在写等于纯负担。M1 加第二个阶段时再看是否需要。
