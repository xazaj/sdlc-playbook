## 新引入的待验证问题

- **`~` 能否被正确解析** —— SKILL.md 里写的是 `~/.sdlc/stages/.../DECIDE.md`。agent 读文件通常需要绝对路径，能否自动展开 `~` 尚未验证。若不行，退路是在 `install.sh` 里生成一份展开后的技能副本，而不是软链原文件。
- **两个路由技能会不会互相抢触发** —— 例如"这个界面怎么做"既可能想问设计方案，也可能想问开发流程。
- **软链方式在其他 agent 上是否可用** —— 目前只挂了 Claude Code。pi 有已知的软链重复注册问题（issue #3405），到 M3 要改用复制。
