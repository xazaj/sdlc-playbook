## 为什么收

skills 已经从 prompt 片段长成了一层可复用的能力包。这个目录适合快速看别人怎么切一个 skill，以及有没有现成的轮子。

## 什么时候用

想找某个领域的现成 skill；想比较不同 skill 的结构；给自己的 skill 找命名和分类参考。

## 注意

目录只负责发现，不负责审计。skill 能读文件、跑命令，安装前至少看一遍它调用了什么工具、访问了哪些路径。
