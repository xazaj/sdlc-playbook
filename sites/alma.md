## 为什么收

同时开几个 CLI agent 时，终端窗口很快就不够用。Alma 把每个 agent 会话变成可读的聊天，能看出谁在等你、谁还在跑。

## 什么时候用

本机同时跑多个 Claude Code / Codex / pi 会话；想在手机上看进度；不想在几个终端之间来回切。

## 注意

它解决的是“看见和回复”，不解决任务依赖、worktree 和验收。别把它当成编排层。涉及私有代码时先看清楚数据存在哪里。
