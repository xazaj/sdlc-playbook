## 为什么收

网上关于 Claude Code 的文章很多，但参数、hooks、skills、subagents 的准信只有官方文档。它也是排查“为什么这个配置没生效”的第一站。

## 什么时候用

安装或升级 Claude Code 之前；写 AGENTS.md、skill、hook 之前；遇到某个 flag 或行为不确定时。

## 注意

文档默认展示最新版本，和本机版本可能不一致。先看版本选择器，再看具体页面。实验性能力不要直接放进生产流程。
