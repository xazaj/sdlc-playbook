## 为什么收

试 Gemini 不一定要先写代码。AI Studio 把 prompt、参数、模型对比和 API key 放在一个页面里，适合验证一个想法值不值得接。

## 什么时候用

快速试 Gemini 的 prompt 和结构化输出；拿一个临时 API key；比较不同 Gemini 版本。

## 注意

playground 里跑通不等于生产可用。配额、延迟、地区限制、数据留存都要在正式接入前确认。
