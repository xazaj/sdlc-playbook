## 为什么收

ChatGPT apps 和 agent UI 需要一批专用组件：聊天气泡、状态徽章、支付表单、商品列表。Manifest UI 把这些常见块做成了可复制的 React 组件。

## 什么时候用

做 ChatGPT app 或 agent 前端；需要快速搭一个对话式界面；想参考 agent UI 的常见结构。

## 注意

复制前看依赖和可访问性。组件库不替你决定信息架构，别把 demo 直接当产品。
