## 为什么收

Warp 从终端长成了一个 agent 开发环境：factory as code、任意模型/harness、评测和 benchmark。适合想看“终端里的 agent 工作流”能做成什么样。

## 什么时候用

想把终端、agent 和评测放在一个工作流里；需要看 agent 任务的 benchmark；评估团队级开发环境。

## 注意

它包含云服务和账号体系，和纯本地 CLI 的信任边界不同。先确认代码、日志和密钥会去哪里。
